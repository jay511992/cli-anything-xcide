WmUi 样式库（CSS 类名体系 · 主题 · Wm_ 辅助函数）

本页由本地 Markdown 生成；样式内嵌，无网络、MCP 或浏览器脚本依赖。

WmUi 是炫彩界面库的现成样式库：预置全套 CSS 类名 + bkInfoM 样式宏 + 颜色/字体资源。做界面时挂对 css.name 即可得到完整视觉（三态交互/主题适配/圆角/渐变），无需自己写样式。

与其他 reference 的分工：bkInfoM 宏语法本体（98: 状态码、绘制段、色值编码）见 bkinfom-res.md §1–§5；布局 XML、layout.*、控件专有属性、窗壳见 interface-xml.md；通用代码侧（句柄/CXWindow/事件/列表适配器/拖放）见 xcgui-code.md。本文件只写 WmUi 专有的类名体系、主题机制、Wm_ 辅助函数。

1. 文件结构与引用链

WmUi\
├── WmUi_Base.res        跨主题：字体 + 基础色（type_font / type_color）
├── WmUi_Code.xc         Wm_ 系列辅助函数 + Wm_颜色_* 宏定义
├── Dark\WmUi.res        主题：9 主题色(type_color) + 全部 bkInfoM 宏(type_bkInfo)
├── Dark\WmUi.css        主题：CSS 类 → @WmUi:\样式名 映射
├── Light\WmUi.res
└── Light\WmUi.css

加载顺序（不可变）：WmUi_Base.res → 主题 WmUi.res → 主题 WmUi.css（CSS 里 @WmUi:\* 才能解析）。 xcproj 用 <default_css path="WmUi\Light\WmUi.css" /> 供设计器使用；资源以 UI_ZIP 打包嵌入 exe（exe.rc 定义 IDR_UI_ZIP，xcproj ui_loadType="1"）。

引用链：布局 XML css.name="类名" → CSS .控件类型 类名{ bkInfoM:@WmUi:\样式名 } → WmUi.res 的 type_bkInfo 宏 → 色值（随主题变化）。

CSS 选择器三形态（WmUi 层）

/* ① 类型选择器 + 类名（css.name 的值） */
.buttonUI 三态按钮_主要_填充_R4{
	bkInfoM:@WmUi:\三态按钮_主要_填充_R4;
	cursor:IDC_ARROW;
	transparent:true;
}
/* ② 子部件选择器：控件内部构件按 style 标识 */
buttonUI[style:scrollbar_slider_h]{ bkInfoM:@WmUi:\滚动按钮_水平; transparent:true; }
/* ③ 裸类型选择器：该类型全体（滚动条自动套用即靠此） */
scrollBarUI{ bkInfoM:@WmUi:\通用滚动条; showButton:false; transparent:true; }

CSS 属性集：bkInfoM transparent cursor padding border textAlign caretColor textColor showButton。 值引用：@WmUi:\样式名（主题 res 的样式宏）、@WmUi_Base:\颜色或字体名（跨主题资源）、字面量（IDC_ARROW、DT_LEFT,DT_VCENTER,DT_SINGLELINE、true/false、数字）。

2. 类名目录（选样式用）

类名必须与 CSS 中 .控件类型 类名 逐字一致（含中文下划线位置）。Dark/Light 两主题类名通用。

2.1 三态按钮（普通按钮，6 色系 × 5 变体 × 3 圆角 = 78 类）

公式：三态按钮_{色系}_{变体}_R{圆角}；链接类无 R 段：三态按钮_{色系}_链接

色系语义变体 → 效果
主要主操作色（品牌蓝）填充=实底；渐变=45°双色渐变底；边框=描边；文字=无底色变色文字；链接=纯文字链接
次要灰阶次要操作同上
警告危险/警示（红橙）同上
明亮高亮强调（亮黄绿）同上
白色深色底上的白按钮同上
黑色浅色底上的黑按钮同上

圆角：R4（紧凑）/ R8（标准，最常用）/ R16（大按钮、胶囊感）

选型速查：主操作→三态按钮_主要_填充_R8；危险→三态按钮_警告_填充_R8；次要/取消→三态按钮_次要_填充_R8 或 三态按钮_次要_文字_R8；强调→三态按钮_明亮_渐变_R8；浅色卡片上→三态按钮_黑色_填充_R8，深色卡片上→三态按钮_白色_填充_R8；行内文字操作→三态按钮_主要_链接/三态按钮_警告_链接；关闭按钮→三态按钮_警告_链接（配 buttonType="close" + 图标字体）；大按钮（高≥60）→R16 + 微软雅黑_s19。

<buttonUI content="确定" css.name="三态按钮_主要_填充_R8" layout.height="40" layout.width="auto" padding="10,0,10,0" />
<buttonUI content="取消" css.name="三态按钮_次要_文字_R8" enable="false" />

按钮 padding 常用 10,0,10,0；大按钮 20,0,20,0。

2.2 六态按钮（普通/悬停/按下/选中/悬停选中/禁用，23 类）

类名用途关键点
六态按钮_勾选复选框buttonType="check"，padding:30,0,10,0（左留勾图区）
六态按钮_标签可关闭标签页buttonType="check"，padding:10,0,35,0（右留关闭区）
六态按钮_开关开关buttonType="check"，padding:40,0,10,0
六态按钮_点选单选框buttonType="radio"，padding:30,0,10,0
六态按钮_展开收缩_上下折叠展开箭头钮配图标字体
`六态按钮高亮{全\左\上\右\下}_R8`高亮标签页按钮选中态高亮；方向=哪侧圆角
`六态按钮灰色{全\左\上\右\下}_R8`灰色标签页按钮未选中偏灰
`六态按钮线型{左\上\右\下}_{直角\_R8}`线型指示 tab不设间距，线才连贯

绘制区核对：控件尺寸和 padding 不能证明勾选图形没有裁切。若继承宏按 20px 盒子绘制，24px 控件仍可能右越界；检查 CSS bkInfoM 实际目标、98: 状态映射、颜色/字体和渲染 bbox，必要时复制为紧凑宏后同步 CSS 引用。

Tabs 组合：容器 layoutEleUI layout.space="10" 放多个 buttonType="radio" 的高亮全R8；方向 tab 用对应方向类；线型 tab 用 layout.space="5" 或不设。 联动：radio 组内 check="true" 设默认选中，bindEle="@面板id" 联动切换面板（面板写法见 interface-xml.md）；禁用 enable="false"。

2.3 容器背景（七家族同构矩阵）

公式：{家族名}_{填充1..7 或 渐变_色组}_R{4|8|16|24}

家族（CSS 前缀）类名前缀典型用途
基础元素 .elementUI基础元素_*任意容器/卡片背景（最常用）
布局元素 .layoutEleUI布局元素_*布局容器（可含子控件、带 padding）
布局框架 .layoutFrameUI布局框架_*布局框架容器
窗口 .windowUI基础窗口_*窗口背景
模态窗口 .modalWindowUI模态窗口_*弹窗/信息框背景
框架窗口 .frameWindowUI框架窗口_*带系统边框的窗口背景
滑动条 .sliderBarUI滑动条_*（仅 R4）滑动条轨道
  • 填充1..7：跟随主题的 7 档中性色（深色主题由深到浅 = #141414→#808080，浅色主题反转）。填充1 = 主背景，填充2 = 次级面板/弹层，填充3+ = 更浅层次（hover 层）
  • 渐变色组（14 组，主题无关固定色）：红炽热、红柔和、橙活力、橙沉稳、黄明亮、黄奢华、绿宁静、绿活力、青清凉、青温润、蓝深邃、蓝平和、紫梦幻、紫_浪漫
  • 圆角 R4/R8/R16/R24 全家族都有（滑动条仅 R4）

选型速查：页面主背景→基础窗口_填充1_R4；卡片/面板→布局元素_填充1_R8 或 布局元素_填充2_R8；搜索框外壳→布局元素_渐变_绿_宁静_R4 padding 3,3,3,3；徽标/角标（99+、SVIP、Hot）→布局元素_渐变_红_炽热_R8 + 内嵌 shapeText；小圆点标记→基础元素_渐变_橙_活力_R4 配 layout.height="8" layout.width="8"；信息框弹窗→模态窗口_填充2_R8；徽章类小标签高度 20~25、padding 5,5,5,5。

2.6 工具条 / Tab条 / 滑动条 / 滚动条 / 进度条

  • 工具条 toolBarUI：无需样式类，放进 布局元素_填充2_R8 容器 + transparent="true" toolBar.space="10"；内部按钮代码置三态按钮类
  • Tab条 tabBarUI：放进容器 + transparent="true"；标签样式代码 Wm_Tab条_置标签样式(句柄)（默认 六态按钮_高亮_全_R8）
  • 滑动条 sliderBarUI css.name="滑动条_渐变_红_炽热_R4"：轨道用任意渐变/填充类（仅 R4）；滑块代码置 三态按钮_{色系}_{填充|边框}_R8
  • 滚动条：自动套用（CSS 裸选择器 scrollBarUI + [style:*] 子部件），布局里无需声明
  • 进度条 progressBarUI：无 CSS 类，样式走代码绘制 Wm_进度条_绘制（三种样式：覆盖/内嵌/偏移）

4. 新增样式类 / 新增主题

4.1 新增一个样式类（三步）

  1. WmUi.res（Dark 与 Light 各加一条）：在 <type_bkInfo> 加 <item name="新样式名" type="22" bkInfoM="{...}" bkInfoM_nameT="0(矩形)..." description="" />（两主题同名，色值各自适配）。宏写法模板见 bkinfom-res.md §1、§3
  2. WmUi.css（两主题各加一条）：.buttonUI 新样式名{ bkInfoM:@WmUi:\新样式名; cursor:IDC_ARROW; transparent:true; }（前缀按控件类型选 buttonUI/elementUI/layoutEleUI/windowUI…）
  3. 使用：XML css.name="新样式名" 或代码 可视对象_置CSS名称(句柄, "新样式名")

type 取值（同 resource.res type_id 体系）：1 窗口、2 模态窗口、3 框架窗口、21 基础元素、22 按钮、24 组合框、25 滚动条、27–30 列表族、32 滑动条、34 工具条、35 月历、36 日期时间、45 编辑框、52 列表头、53 布局元素、54 布局框架。

4.2 新增主题（复制法）

  1. 复制 Light\ 目录为 我的主题\（WmUi.res + WmUi.css）
  2. 只改 WmUi.res 中 9 个主题色的 value——所有填充/按钮系样式引用的色值随之重排；渐变系为固定值可不动
  3. 若文字色需调整，改 CSS 中少数 caretColor/textColor:@WmUi_Base:\白色|黑色
  4. 代码切换：炫彩_加载资源文件内存ZIP(局_UIzip, 资源大小, "WmUi\\我的主题\\WmUi.res") + 炫彩_加载样式文件从资源ZIP(IDR_UI_ZIP, "WmUi\\我的主题\\WmUi.css") + 重绘()
  5. 类名体系完全不动，布局零修改

5.4 磁盘资源模式、部署与加载失败（WmUi 工程实测）

原示例的 ui_loadType="1" + IDR_UI_ZIP 是一种打包方式，不是 WmUi 唯一加载方式。使用磁盘布局／资源时，可用 ui_loadType="0"，按当前模块的磁盘加载 API 显式调用 Base → 主题 .res → 主题 .css，再加载项目自身 resource.res。<default_css path="..." /> 供设计器使用，不能据此推定运行时已经加载 CSS；仍要执行运行时代码。

// 路径应按 EXE 所在目录构造，不要依赖当前 cwd。
如果 (!炫彩_加载资源文件(主题根 + "WmUi_Base.res"))
	返回 4
如果 (!炫彩_加载资源文件(主题根 + "Dark\\WmUi.res"))
	返回 4
如果 (!XC_LoadStyle(主题根 + "Dark\\WmUi.css"))
	返回 4
如果 (!炫彩_加载资源文件(项目资源根 + "resource.res"))
	返回 4
  • 路径只表示本项目采用的相对布局；主题根和项目资源根必须由实际 EXE 路径得到。用与项目模块一致的磁盘 API 名称和路径转义。
  • 每一步都检查返回值，全部成功后才创建窗口。失败时退出并写诊断，不能继续使用未注册字体／颜色造成“看起来启动了但样式丢失”，也不能把静态资源检查当成实际加载成功。
  • 发布目录必须完整包含：XCGUI 动态库（若工程为 moduleLib="dll"）、全部窗口布局、列表／树／组合框模板、resources/、整个 WmUi/（Base、当前主题、CSS，以及 .res 中 fontFile 指向的字体文件等）。不能仅复制两个 .res 或只部署 XML。
  • moduleLib="dll" 与静态链接是两条配置路径：保留 DLL 配置就部署匹配架构的 XCGUI DLL；想切 moduleLib="lib" 前先确认对应 x64/static-lib/static-XCGUI.lib 实际存在。本机实测缺失该静态库时，不要硬改配置冒充完成。
  • 构建后可能出现“exe 目录同名 XML 内容不同”的提示；此时显式部署源目录中的最新布局／模板／主题／字体。部署合并而非清空未知用户文件，逐文件校验源／目标 SHA-256，并拒绝重解析点／目录链接，避免通过输出目录写到别处。

WmUi 的 六态按钮_开关 只负责视觉状态；buttonType="check" 的默认翻转、失败回滚和业务真实状态同步见 xcgui-code.md §6.5。不能因样式显示为“已选中”就认定热键、监听或其他动作已成功启动。

6. WmUi 窗口与信息框骨架

最小窗口：windowUI 用 css.name="基础窗口_填充1_R4" + transparentFlag="shadow" shadowDepth="128" shadowSize="15" + dragWindow/dragBorder/overlayBorder="true" + enableLayout="true" layout.space="10"；标题栏用 layoutEleUI layout.height="40" layout.width="fill"，内含 shapeText（font="@WmUi_Base:\微软雅黑_s15" textColor="@WmUi:\主文本色"）与三个 buttonType="min|max|close" 按钮（min/max = 三态按钮_次要_链接，close = 三态按钮_警告_链接，均配 font="@WmUi_Base:\图标字体_s12"）。窗口属性全集见 interface-xml.md §4。

信息框标准结构（WmUi\control\窗口_信息框.xml）：

windowUI(windowType="modalWindow" 模态窗口_填充2_R8 topmost center minSize="360,0" shadow 20/128/8 dragWindow)
├─ layoutEleUI 布局元素_对话框标题  → shapeText 标题 + buttonUI buttonType="close" 三态按钮_警告_链接(图标字体_s12)
├─ layoutEleUI 布局元素_填充1_R8    → shapeText 正文（margin 10,0,10,0 padding 10,15,10,15）
└─ layoutEleUI 布局元素_对话框按钮  → 确定=三态按钮_主要_填充_R8 / 取消=次要_填充_R8 / 重试=明亮_填充_R8

7. Dark/Light 差异备忘

  • 类名/结构完全同构（选择器一一对应）；多数条目 98: 状态映射相同，少数存在矩形数量差异：六态按钮_高亮_上_R8（Dark 5 矩形 272(0)288(1)320(2)144(2)160(2)192(3)2(4)，Light 4 矩形 272()288(0)320(1)144(1)160(1)192(2)2(3)）、月历卡片_普通（18560 段 Light 多挂 6）、三态按钮_次要_渐变_R16（Dark 16(0)32(1)64(2)2(3)，Light 16(0)32(2)64(3)2(1)）——对外交互行为一致
  • 文字色：编辑框/组合框/日期时间/月历 Dark 用 @WmUi_Base:\白色，Light 用 @WmUi_Base:\黑色
  • 渐变色组两主题同值（不随主题）

8. 生成 WmUi 界面的选型硬规则

  1. 按钮一律用 三态按钮_色系_变体_R圆角（主操作=主要填充，危险=警告填充，低调=次要_填充/文字，彩色卡片背景=渐变）
  2. 卡片/面板用 基础元素_填充1..7_R8（随主题）或 渐变_色组
  3. 弹窗/菜单/信息框用 基础窗口_填充2_R8 / 模态窗口_填充2_R8 + 代码设阴影（窗口_置阴影信息(句柄, 10, 128, 8, 假, 0) + 四周扩 10px）
  4. 文本输入用 编辑框_通用_R8（Dark 白字 / Light 黑字由主题 CSS 自动处理）
  5. 列表容器类名统一 *_普通；列表项内放按钮时用按钮类，写在模板 XML 里
  6. 滑动条轨道用 滑动条_填充*/滑动条_渐变_*_R4，滑块代码置 三态按钮_*_填充_R8
  7. 新主题只复制 Light 目录改 9 个主题色，类名体系与布局零修改
  8. 类名、颜色名、字体名必须与 CSS/.res 逐字一致；不确定时先查本文件 §2–§3，不要臆造类名
