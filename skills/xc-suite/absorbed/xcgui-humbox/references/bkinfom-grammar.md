# bkInfoM 样式宏语言完整语法

bkInfoM 是炫彩界面库 (XCGUI) 的样式宏语言，出现在几乎所有元素的 `bkInfoM="..."` 属性上。它是整个体系中最难的知识——库本身没有公开文档，以下语法是从 humbox 项目全部 57 个布局文件中反推归纳的。**写或改任何 bkInfoM 之前先读完本文。**

## 1. 整体结构

bkInfoM 是一个被 `{}` 包裹的、以 `;` 分隔的**分段序列**。每段格式为 `编号:参数(值列表)` 或 `编号(...)`：

```
{sizeT:W,H; 99:1.9.9; 98:状态映射; <绘制段0>; <绘制段1>; <绘制段2>; ...}
```

- 段与段之间用 `;` 分隔，最后一个段后通常也带 `;` 再闭合 `}`
- **绘制段按出现顺序从 0 开始编号**（段0、段1、段2…），`98:` 状态映射里的数字就是这些段的索引
- 配套属性 `bkInfoM_nameT="0(矩形)1(文字)2(图片)"` 给每个段一个设计器里的人类可读标签——修改时对照它定位段落

### 头部段

| 段 | 作用 | 示例 |
|---|---|---|
| `sizeT:W,H` | 设计参考尺寸（可选，仅设计器使用） | `sizeT:120,20` |
| `99:1.9.9` | bkInfoM 格式版本号，**必须写** | 所有文件恒为 `99:1.9.9` |
| `98:...` | 状态→绘制段映射，决定交互时用哪套段 | 见下节 |

## 2. 状态映射 `98:` —— 交互状态表

`98:` 里每项格式为 `状态码(段索引列表)`。同一码出现多次时后项覆盖/叠加前项（如 `98:16(0,1)32(2,1)64(3,1)2(4,5)`：正常态画段0+1，悬停改画段2+1，按下改画段3+1，选中态画段4+5）。

### 已从项目实例确认的状态码

| 状态码 | 含义 | 典型用法 |
|---|---|---|
| `16` | leave/normal——离开（默认）态 | `16(0)` 普通按钮；`16(0,1)` 窗口背景=段0、边框=段1 |
| `32` | stay/hover——鼠标悬停 | `32(0,3)` 悬停时叠加段3 |
| `64` | down/press——按下 | `64(1,4)` |
| `2` | check/select——选中态 | `2(3)` 选中时画段3 |
| `128` | check+leave（选中且未悬停） | `128(0,1,3,4)` |
| `144` | check+stay（选中且悬停） | `144(2,6)` |
| `160` | check+down（选中且按下） | `160(3,6)` |
| `192` | check 另一变体 | `192(2,6)` |
| `272` | radio-leave（单选未选中） | `272(0,4)` |
| `288` | radio-stay（单选悬停） | `288(1,4)` |
| `320` | radio-down（单选按下） | `320(1,4)` |
| `258` | radio-check（单选选中） | `258(3)` |
| `130` | radio-check 变体（选中高亮） | `130(3)` / `130(5,2)` |
| `24` | comboBox 编辑框态 | `24(0,1)` |
| `20` | comboBox 弹起态 | `20(0,1)` |
| `40` | comboBox 按钮态 | `40(0,1)` |
| `36` | comboBox 下拉态 | `36(0,1)` |
| `72` | comboBox-2（悬停） | `72(0,2)` |
| `68` | comboBox-2（按下） | `68(0,2)` |
| `1` | 窗口绘制序（login.xml 顶层窗口用到 `98:1(0,2,3,1)`） | 特例 |
| `8` | 单选禁用/半透明变体（skin.xml 单选） | `272(8,1,0)` |

各码可组合叠加：`98:16(0)32(2)64(3)2(1)` 表示四个态各画不同段。**每态的段列表是从 0 计数的绘制段索引**，且通常包含一个"底图/底色段"（索引 0 或 1）再加修饰段。

## 3. 绘制段语法

每个绘制段以 `类型:对齐(参数)更多(参数)` 形式出现。类型决定画什么，参数编号决定细节。

### 3.1 图片段 `3:`

```
3:<对齐码>(缩放码)3(l,t,w,h)4(@图片名)
```

| 项 | 说明 |
|---|---|
| 对齐码 | `2`、`15`、`18`、`33`、`36`、`41`、`48` 均有出现；`15`=拉伸填充、`33`=居中、`48`=居中原始、`41`=内容槽（见 3.5）、`36`=居中裁剪 |
| `3(l,t,w,h)` | 相对元素左上角的绘制区域。注意：**w,h 为 0 表示自动取图片原始尺寸**；`3(0,0,0,32)` 常见于"从上往下画 h=32" |
| `4(@名)` | 图片引用，经 resource.res 的 type_image 注册名解析。也可绑数据：`4({binding field=缩略图})` |

实例（login.xml 关闭按钮，三态换图）：
```
{99:1.9.9;98:16(0)32(1)64(1)2(2);3:2(48)3(24,24,24,24)4(@close1.svg);3:2(48)3(24,24,24,24)4(@close2.svg);3:2(48)3(24,24,24,24)4(@close3.svg);}
```
→ 正常画 close1.svg，悬停/按下画 close2.svg，按下画 close3.svg（24x24 居中）。每段完整语法是 `3:2(48)3(24,24,24,24)4(@close1.svg)` ——`3:` 后的第一个括号是对齐方式(48=center)。

### 3.2 矩形/边框段 `5:`

```
5:<对齐码>(区域码)3(l,t,r,b) 20(边宽)21(边样式)26(接角) 22(颜色)23(透明度) 9(圆角,圆角,圆角,圆角) [24(渐变) 或 10..16(多层描边)]
```

| 参数 | 说明 |
|---|---|
| 区域码 | `3` = 元素整体区域；`15` = 同 3；`7`/`11` = 头部条带（配合 `3(0,0,0,32)` 画顶部 32px 高的标题栏）；`18` = 自定义区域 |
| `3(l,t,r,b)` | 内容区偏移（常与 padding 配合），`3(1,1,1,1)` 即收缩 1px 让边框不糊 |
| `20(1)` | 边框宽度 1px |
| `21(3)`/`21(4)` | 边框样式（3=实线、4=渐变线） |
| `26(1)` | 圆角连接处平滑 |
| `22(颜色)` | 32 位打包颜色，**有符号十进制**（见第 4 节换算） |
| `23(透明度)` | 0–255，255=不透明 |
| `9(r,r,r,r)` | 四角圆角半径，可四值不同（如 `9(2,2,0,0)` 仅上圆角） |
| `24(2,角度,起始色,0,结束色,100)` | 线性渐变：2=线性、角度单位为度（0.00=水平、90.00=垂直）、多停靠点格式 `24(2,30.00,C1,0,C2,100,C3,33,C4,66)` 即 0%/33%/66%/100% 四色 |
| `10(1)7(1)11(3)16(1)12(色)13(α)` | 渐变描边（边框自身用渐变色）：`10` 启用、`7` 样式、`12(色)13(α)` 渐变端颜色 |
| `40(1)` | 未知修饰位（头像框、elementUI 常见，照抄即可） |

**最常用的"卡片底"配方**（半透明深色圆角矩形 + 内层渐变描边）：
```
5:2(15)20(1)21(3)26(1)22(654311423)23(38)9(2,2,2,2)
```
→ 全区域 1px 描边圆角矩形，填充色 654311423、透明度 38（约 15% 白）。这是 skin.xml 表单容器的实际底色。

**渐变按钮配方**（home.xml 首页卡片）：
```
5:2(15)20(1)21(4)26(1)24(2,90.00,-252842773,0,-253105945,100)9(2,2,2,2)
```
→ 垂直 90° 线性渐变，从 -252842773 到 -253105945（深紫到深蓝），圆角 2。

### 3.3 内嵌/按下修饰段 `6:`

语法与 `5:` 完全一致，语义上是"叠加修饰层"——项目中用于内阴影、按压加深、头像底圈等。例如头像框选中态：
```
6:2(15)20(1)21(3)26(1)22(201326592)23(12)10(1)7(1)11(3)16(1)12(-587202561)13(220)
```
→ 半透明 12/255 的选中蒙层加 220 透明度的渐变描边。

### 3.4 文字段 `7:`

```
7:<对齐码>(区域码)3(l,t,w,h)30(对齐标志,文字)21(3)31(@字体名)32(字形标志)22(颜色)23(透明度)
```

| 参数 | 说明 |
|---|---|
| 区域码 | `15`=全区域、`3`/`7`/`6`/`11`=局部条带 |
| `3(l,t,w,h)` | 文字绘制区域（w,h 为 0 时自动） |
| `30(对齐标志,文字)` | 对齐标志是 DrawText 式标志之和：`2`=DT_LEFT? `4`=居左、`5`=带图标左对齐、`6`=居中、`7`=整宽居中、`11`/`12`=右上/右下。文字内容直接写在里面，如 `30(2,首页)` |
| `31(@字体名)` | 经 resource.res 的 type_font 注册名，如 `@13b`、`@10b` |
| `32(标志)` | 字形标志：`36`=常规、`37`=加粗、`38`=斜体、`32804`=带阴影/描边变体 |
| `22(颜色)`、`23(α)` | 文字色与透明度 |

实例（main.xml 主导航"首页"，四个交互态各一段文字）：
```
7:2(15)30(2,首页)21(3)31(@13b)32(37)22(-1291845633)23(178);   ← 正常：灰白
7:2(15)30(2,首页)21(3)31(@13b)32(37)22(-922746881)23(200);  ← 悬停：亮一点
7:2(15)30(2,首页)21(3)31(@15b)32(37)22(-1)23(255);           ← 选中：纯白 + 更大字号 @15b
7:2(15)30(2,首页)21(3)31(@13b)32(37)22(1694498815)23(100);   ← 按下：半透明
```

### 3.5 内容槽段 `3:41`（绑定子内容）

`3:41(编号)2(对齐)4()` 是"占位槽"——段内没有实际内容，由运行时填充（如头像图片）。常见于 resource.res 的头像样式：
```
3:41(1)2(15)4();            ← 空槽（头像底）
3:41(2)2(15)4(@头像框1_120x120_01.png)40(1);  ← 槽2=头像框图片
```

### 3.6 段内其他零散编号

在 `5:`/`6:` 段尾部偶见，反推含义：
- `40(1)`：跟随修饰（几乎所有图片段/装饰段都带，保持原样即可）
- `10(1)7(N)11(N)16(1)12(色)13(α)`：渐变描边组
- `12(...)` `13(...)` 是渐变描边的起/止色对；单独的 `22()23()` 是填充色对

## 4. 颜色编码

bkInfoM 内所有颜色都是 **32 位有符号十进制整数**（ARGB 打包），而 XML 属性里的颜色是 `#AARRGGBB` 十六进制（如 `textColor="#FDFFFFFF"`）。两者换算：

```
有符号数 = ARGB 无符号数超过 0x7FFFFFFF 时的值 - 0x100000000
示例：-1291845633 → 无符号 = 4294967296 - 1291845633 = 3003121663 → 十六进制 0xB2FFFFFF → #B2FFFFFF（70% 透明白）
```

**操作规则：改色时先算无符号值**（`<0` 则加 4294967296），转十六进制得 AARRGGBB，改完再转回有符号十进制写回。工具链用 Python 一行即可：
```python
n = -1291845633; u = n & 0xFFFFFFFF; f"#{u:08X}"        # → '#B2FFFFFF'
c = 0xB2FFFFFF; str(c if c < 0x80000000 else c - 0x100000000)  # → '-1291845633'
```

humbox 常用色速查（有符号 → 十六进制，全部经上式验证）：

| 有符号值 | 十六进制 | 用途 |
|---|---|---|
| `-1` | `#FFFFFFFF` | 纯白文字（选中态） |
| `-1291845633` | `#B2FFFFFF` | 70% 白文字（正常态） |
| `-922746881` | `#C9FFFFFF` | 悬停文字白 |
| `-14736351` | `#FF1F2421` | 深墨绿——强调按钮文字色 |
| `654311423` | `#26FFFFFF` | 15% 白——卡片底色 |
| `-3618616` | `#FFC8C8C8` | 浅灰——头像底圈 |
| `-587202561` | `#DCFFFFFF` | 86% 白——登录按钮底 |
| `-1579033` | `#FFE7E7E7` | 白色滚动条 |
| `1503907412` | `#59A3CE54` | 复选框禁用态（绿调） |
| `1694498815` | `#64FFFFFF` | 39% 白——按下文字 |
| `419496450` | `#19010202` | 10% 深色——输入框底 |
| `855638015` | `#32FFFFFF` | 20% 白——悬停底 |
| `687865855` | `#28FFFFFF` | 16% 白——悬停描边底 |
| `352321535` | `#14FFFFFF` | 8% 白——内层描边 |
| `-419430401` | `#E6FFFFFF` | 90% 白——主按钮正常底 |

## 5. 命名样式复用：`bkInfoM="@名称"`

resource.res 的 `<type_bkInfo>` 节注册了可复用样式，布局里直接引用名称（等价于 CSS class）：

```xml
<buttonUI bkInfoM="@滚动条" transparent="true" childType="scrollBarV.button" />
```

humbox 已注册的命名样式见 file-map.md 第 4 节（滚动条、滚动条_白色、复选框、头像0-3_主页面/个人信息、头像框0-3_编辑头像、头像预览0-3）。**同类控件多处出现时优先定义命名样式再引用**，避免逐处复制长字符串。

## 6. 修改 bkInfoM 的实操守则

1. **先找同款**：项目内 99% 的样式诉求都有现成配方（按钮、卡片、输入框、单选、滚动条……）。在 布局文件/ 里全文搜索目标样式关键词（如 `9(4,4,4,4)` 圆角4、`24(2,90.00` 垂直渐变）复制段串改参数，而不是从零拼。
2. **段索引联动**：增删绘制段会改变后续段的索引，`98:` 里的映射必须同步改。改之前先数一遍段。
3. **bkInfoM_nameT 同步**：设计器用 `bkInfoM_nameT="0(矩形)1(文字)"` 记录每段语义；手写时补上（或至少不删除），便于后续维护。
4. **对齐码宁抄勿猜**：`2/3/6/7/11/15/18/33/36/41/48` 各值的确切含义未 100% 确证，**一律从项目现成段落抄对齐码**，只改颜色/尺寸/圆角/文字等确定参数。
5. **图片名必须已注册**：`4(@名)` 里的名字要在 resource.res 的 type_image 有对应条目，否则运行时不显示。
6. **保持 `;` 收尾**：每段末尾 `;`、`}` 前的最后一段也带 `;`，与项目所有实例一致。

## 7. 逐段注释的真实完整实例

### 实例 A：main.xml 主导航单选按钮（首页）

```xml

    7:2(15)30(2,首页)21(3)31(@13b)32(37)22(-922746881)23(200);    ← 段1 悬停文字
    7:2(15)30(2,首页)21(3)31(@15b)32(37)22(-1)23(255);            ← 段2 选中文字(15b 大号纯白)
    7:2(15)30(2,首页)21(3)31(@13b)32(37)22(1694498815)23(100);    ← 段3 按下文字
```

## 8. 未确证项（修改时保持原样，勿"修正"）

- `98:1(...)` 的确切语义（仅 login.xml 顶层窗口出现一次）
