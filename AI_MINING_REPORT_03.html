结果与范围

取证脚本直接读取的 249 个文件 SHA-256 前后一致。样本包括 38 张磁盘资源表、95 个布局 XML、5 个 UI ZIP、77 个工程文件、5 个目标模块头及相关配置/资产。脚本另外完成 13 次已安装命令检查，其中一次实际导出到独立临时新文件；没有改写安装目录、原工程或正式 IDE 配置。

扫描范围为 data/示例、data/template、data/xml，以及 例子/炫彩界面AI项目、例子/音量控制，跳过构建与工具生成目录。模块声明采用明确选出的 5 个头文件，未声称分析整个模块库的全部 API。249 是取证文件数，并非安装目录的全部文件数，也不包括依赖命令内部扫描但未逐个取证的头文件。

本轮最有实际影响的发现：

  • 资源表有递归 folder 分类。360 安全卫士模板的 4 个分类都叫“新建分类”，并不是 4 个同名资源；QQ 音乐的“音乐馆”分类含 12 张图片。新命令递归读取分类内资源，另返分类元数据。
  • 38 张资源表共取得 1777 条资源记录、496 张图片、19 个分类；677 个名字在多张表中复用，当前样本没有同表资源重名。名字不能作为跨表唯一标识。
  • 499 个磁盘图片/字体文件引用中，497 个可按资源表目录找到，2 个找不到：登录 UI 的 Abduction2000.TTF，以及仿 mos 模板引用的 ..\默认窗口模板设计\exe.ico。这是相对路径存在性结论，未证明程序运行时一定失败。
  • 5 个 ZIP 的 42 个成员中，34 个原始名字使用反斜杠；列表 ID 使用正斜杠，另存原始名字，并按 ZipInfo 读取。42 个成员本轮均完成 CRC 校验，42 个磁盘对应文件均与包内字节相同，未发现副本内容漂移。
  • WmUi 暗色与亮色资源表各有 483 个命名资源，280 个同名资源的属性不同；不可按名字去重。两个字体资源指向包内 Font Awesome 文件，4 个系统字体资源不应被当成缺失文件。
  • 11 个布局节点的 showT 与 show 明确不同；原生绑定还出现在图片和背景样式中。CLI 保留原值，不将设计器显示、运行时显示和绑定结果混为一谈。

新命令与 AI 调用链

命令可用能力结果边界
archive list FILE [QUERY]分页列出规范化 ID、原始名字、大小、压缩方式和路径问题。只读目录，crc_verified=false；readable 不是解压成功保证。
archive read FILE MEMBER校验选中成员 CRC，读取 UTF-8/UTF-16/GB18030 文本。不将二进制控制字符当文本输出。
archive export FILE MEMBER OUTPUT按原始字节导出单个成员，回读核验并发布到新文件。父目录需存在且支持硬链接；不覆盖、不写安装目录、不批量解包。
resource list FILE [QUERY]读取磁盘或 ZIP 中任意 resources XML，支持 --member、--kind。递归分类另列；资产存在性不是格式或运行时验证。
resource show FILE ID按准确位置 ID 取资源属性、XML 和资产状态。ID 随文件结构变化，必须结合源哈希。
interface nodes FILE [QUERY]读取父子层级、原生属性、绑定和 head，支持标签、属性/值过滤。不计算几何、可见性、数据绑定值。
interface node FILE ID返回准确节点和完整子树 XML。XML 为重新序列化；原始字节使用 archive export。
$zip = 'I:\xcide\data\template\项目模板\炫语言\用户模板\暗黑UI\project\UI_ZIP.zip'
cli-anything-xcide --json --dry-run --ide 'I:\xcide' archive list $zip
cli-anything-xcide --json --dry-run --ide 'I:\xcide' resource list $zip --member 'WmUi/Dark/WmUi.res' --kind type_bkInfo --limit 10
cli-anything-xcide --json --dry-run --ide 'I:\xcide' resource list $zip --member 'WmUi/WmUi_Base.res' --kind type_font
cli-anything-xcide --json --dry-run --ide 'I:\xcide' interface nodes $zip --member 'main.xml' --tag buttonUI

从 items[].id 取准确 ID 后调用对应 show/node；翻页用 next_offset。磁盘结果有 source.sha256，ZIP 结果另有 source.archive.sha256。跨命令比较哈希，文件变化就重新列表。--dry-run 查询返回真实数据，同时禁止会话写入；实际导出需移除该开关。

新查询限制：ZIP 64 MiB/10,000 个条目、单成员解压 8 MiB；XML 4 MiB、20,000 个节点、深度 128。不解析 DTD/实体声明。路径冲突、穿越、Windows 保留名、符号链接、加密或超限成员会拒绝读取/导出。源文件限定在所选工程或 IDE 目录内。原有 interface list/check 和构建逻辑没有改用这套新解析器。
